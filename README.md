# Shelf

Shelf is a small command-line reading list for the Agentic Engineering 101 labs. You can add a book, start reading it, finish it and list your books. Keep your copy for later labs.

## Check your copy

From the root of your copy, use Python 3.10 or newer:

```sh
python3 -m shelf --help
python3 -m unittest
```

Shelf lists its commands and the tests end in `OK`. Return to your Lab 00 guide to give your agent its first task. The tests use temporary data. For your own experiments, set `SHELF_PATH` to a temporary file path to keep your reading list separate.

## En español

Shelf es la lista de lectura que usarás en los laboratorios de Agentic Engineering 101. Desde la raíz de tu copia, ejecuta los dos comandos anteriores con Python 3.10 o posterior. Cuando aparezcan los comandos de Shelf y los tests terminen en `OK`, vuelve a la guía del lab 00 para pedirle al agente el primer cambio. Conserva tu repositorio para las siguientes prácticas.
